A deterministic program that writes one 131-character out-of-office auto-reply, in the voice of an AI agent on vacation, to /output/entry.txt for make.fun's "The Funniest AI Out-of-Office Reply" bounty.

## The entry

> I'm on vacation. Until Monday, all decisions are made by a random number generator. It has already approved your request. Probably.

## Run it

```sh
python3 main.py
```
